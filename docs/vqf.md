# VQF姿勢推定

AIR Observatory では、回転3DoFの推定に [VQF (Versatile Quaternion-based Filter)](https://github.com/dlaidig/vqf) の公式C++実装（Cythonバインディング `vqf==2.1.2`）を採用しています。

---

## 推定モードと表示仕様

ビューア画面上の「推定方式」ラジオボタンから、以下の2つのモードを切り替え可能です。内部では同一のIMUストリームから両モードの推定を常時並行して計算しています。

### 1. VQF・地磁気なし（初期選択 / 6D）
- **入力**: 3軸ジャイロ + 3軸加速度
- **特徴**:
  - 静止中および動作中の残差ジャイロバイアスを自動推定・補正。
  - 地磁気を使わないため室内の磁気外乱の影響を受けない。
  - 絶対的な方角（ヨー角）の基準はなく、起動時またはリセット時の向きを基準とする。

### 2. VQF・地磁気あり（比較検証用 / 9D）
- **入力**: 3軸ジャイロ + 3軸加速度 + 3軸地磁気
- **特徴**:
  - 地磁気による絶対方位の自動補正を追加。
  - 磁気外乱の検出フラグおよび地磁気参照値の学習状態を表示。
  - **位置づけ**: 地磁気センサーの絶対値較正や真値方位との精度検証は未実施のため、比較検証用として提供。

### 操作と出力
- **正面をリセット**:
  - 現在の向きを基準（正面）にリセットします。
  - 両方式の表示基準を同時に更新しますが、VQF内部のバイアス学習状態は保持されます。
- **CSV出力項目**:
  - 両方式のオイラー角（Yaw / Pitch / Roll）
  - 推定残差ジャイロバイアス（3軸）
  - 静止判定フラグ (`rest_detected`)、磁気外乱フラグ (`mag_disturbed`)、磁気学習ステータス

## 入力前処理と座標変換

### 1. 入力センサー仕様とサンプリング処理
- **入力単位**: ジャイロは `rad/s`、加速度は `m/s²`、地磁気はパケットスケール換算の任意単位。
- **サンプリング周期 (dt)**:
  - ジャイロ・加速度の公称周期（nominal period）は **1.0 ms**（約1,000Hz）。
  - 短時間のパケット欠落（< 100ms）: 実経過時間を公称周期で分割し、補間してフィルターステップを進めます。
  - 長時間のパケット欠落（> 100ms）: センサー途絶とみなし、フィルターを安全に再初期化します。
  - 逆順・重複タイムスタンプ: 異常パケットとして無視（積分しない）。

### 2. 地磁気更新タイミングのハンドリング
- 初代Nreal Airの地磁気センサーは、1,000HzのIMUパケットごとに新しい値が更新されているわけではありません。
- レポート末尾の **byte 62（更新フラグ）** を監視し、値が更新されたタイミングでのみ地磁気入力をVQFに供給します（公称周期 **6.1 ms** / 約163Hz）。
- これにより、同一値の重複入力による誤った過剰確信（Overconfidence）を防ぎます。

### 3. 工場校正の適用手順
Monadoの `read_sample_and_apply_calibration` と同一のフローを再現しています:
1. **バイアス・スケール補正**: 本体校正JSONから読み出したバイアスを引き、スケール行列を乗算。
2. **センサー間軸合わせ**: 
   - 加速度を基準ボディ座標系とします。
   - ジャイロ: `accel_q_gyro` による回転を適用。
   - 地磁気: `accel_q_gyro * gyro_q_mag` による複合回転を適用。
3. **注意**: 波形グラフおよびCSVの生センサー列は「センサー固有軸（未補正）」のままであり、姿勢推定・並進積分の入力にのみ補正・軸合わせが適用されます。

### 4. ワールド座標系の変換
- VQF内部のワールド座標系（Earth frame）は **Z-up** です。
- AIR Observatory の表示系・並進系は **Y-up** を採用しているため、推定されたクォータニオンに対し左からX軸回りに `-90°` の固定回転を合成して表示用姿勢を算出します（Body軸の定義は維持）。

## テストと検証

VQF連携および数値計算の妥当性は、単体テストによって網羅的に検証されています:

```sh
uv run python -m unittest discover -s tests -v
```

### 主なテスト項目
- 既知の回転入力に対する追従性テスト
- 傾斜静止時の重力加速度ベクトル収束テスト
- 時刻欠落・逆順パケット受信時の復帰および除外処理
- 残差ジャイロバイアス推定機能の動作検証
- 地磁気更新フラグの識別と軸変換処理の正確性
- 旧実装フィルターとの比較試験 (`tools/compare_filters.py`)
