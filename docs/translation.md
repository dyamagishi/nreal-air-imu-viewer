# 回転＋並進の6DoF表示

VQFにより推定された回転姿勢クォータニオンを用いて、センサー座標系の加速度をワールド座標系へと回転変換し、重力加速度を除去した線形加速度を二重積分することで、3次元の位置・速度（並進3DoF）を推定します。

---

## 並進推定アルゴリズム

各IMUサンプル（約1,000Hz）について、地磁気なし・ありの双方で以下の積分計算を行います。

### 1. 座標変換と重力除去

$$\mathbf{a}_{\text{world}} = \mathbf{R}(q_{\text{VQF}}) \cdot \mathbf{a}_{\text{calibrated}}$$

$$\mathbf{a}_{\text{linear}} = \mathbf{a}_{\text{world}} - \begin{bmatrix} 0 \\ 9.80665 \\ 0 \end{bmatrix}$$

- ワールド座標系は **Y軸が鉛直上向き (Y-up)** です。
- 初期位置および初期速度はゼロベクトル $\mathbf{0}$ とします。

### 2. 数値積分（台形則）

サンプリング間隔 $\Delta t$（デバイスタイムスタンプから算出）ごとに台形則を適用して速度および位置を更新します:

$$\mathbf{v}(t) = \mathbf{v}(t-1) + \frac{\mathbf{a}_{\text{linear}}(t-1) + \mathbf{a}_{\text{linear}}(t)}{2} \cdot \Delta t$$

$$\mathbf{p}(t) = \mathbf{p}(t-1) + \frac{\mathbf{v}(t-1) + \mathbf{v}(t)}{2} \cdot \Delta t$$

### 3. 欠落・異常値のハンドリング
- **パケット途絶（> 100ms）**: VQFの再初期化に連動して、並進の位置・速度もゼロにリセットし、不明区間の誤積分を防ぎます。リセットごとに `translation_generation` カウンタをインクリメントし、CSV上で積分区間を識別可能です。
- **重複・逆順パケット**: 積分対象から安全に除外します。
- **人工的な減衰・デッドゾーンなし**: センサー挙動をありのまま観測できるよう、勝手な速度減衰や人為的な閾値カットは設けていません。

## 操作と表示仕様

### 1. 各種リセット機能の違い

| 操作ボタン | 対象 | 影響範囲 |
|---|---|---|
| **位置・速度をゼロに** | 並進（位置 $\mathbf{p}$ / 速度 $\mathbf{v}$） | 位置・速度・経過時間をゼロにリセット。**VQFの学習状態や回転基準は維持**されます。 |
| **正面をリセット** | 3D表示座標系（回転・描画基準） | 画面上のメガネモデルや軌跡の正面方向をリセット。**積分中のワールド位置・速度は維持**されます。 |

### 2. 静止時ゼロ速度補正（ZUPT: Zero Velocity Update）
- **機能**: VQFが静止判定（`rest_detected == True`）を出している間、強制的に速度ベクトルをゼロに固定し、位置の発散（ドリフト）を抑止します。
- **初期状態**: **OFF**（ユーザーが明示的にチェックした場合のみ有効）。
- **注意点**: 等速直線運動時にも静止と誤判定される可能性があるため、デフォルトでは無効化しています。補正中も重力除去後の加速度波形はそのまま表示されます。

### 3. 座標系の関係
- **並進グラフ（3枚）**: Y-upの**ワールド座標系**で位置・速度・線形加速度を表示します。
- **3Dビュー**: 「正面をリセット」した時点の姿勢を基準とする**表示ローカル座標系**でメガネモデルと軌跡を描画します。初期姿勢が傾いていた場合、3Dビューのグリッド軸と並進グラフのXYZ軸は異なる点に注意してください。

### 4. 空間範囲（表示スケール）
- **選択肢**: `自動`, `±0.25m`, `±1.0m`, `±5.0m`
- **自動スケール**: 現在位置と直近約10秒間の軌跡が綺麗に収まるよう表示倍率を動的に調整します（内部の数値データは変更しません）。

## 慣性積分の制約と特性

本ビューアは、**IMU単体による純粋なデッドレコニング（慣性航法）の挙動を観察・研究するためのツール**です。

- 外部の位置観測（カメラ、LiDAR、外部マーカー等）による絶対位置補正はありません。
- わずかな重力除去の姿勢誤差やセンサーバイアス、初期速度の不確かさが二重積分によって二次関数的に蓄積し、**時間経過とともに位置ドリフトが生じるのは物理的な必然**です。
- 本ツールではそのドリフトを誤魔化さず、生データおよび推定過程を正確に可視化します。

## 自動テストによる検証

以下の挙動を網羅するユニットテストを実装しています（`tests/test_translation.py`）:

1. **基本積分精度**: $1.0\,\text{m/s}^2$ を2秒間印加した際、理論値通り速度 $2.0\,\text{m/s}$・位置 $2.0\,\text{m}$ に達すること。
2. **ZUPT OFF時の独立性**: 静止フラグが立っても、ZUPTが無効であれば等速運動がキャンセルされないこと。
3. **ZUPT ON時の補正**: 静止フラグが有効な間のみ速度が正確にゼロへ収束すること。
4. **正面リセットと並進リセットの分離**: 正面リセットがワールド積分の位置・速度に影響を与えないこと。
5. **傾斜静止時の重力相殺**: 35°傾いた静止状態において重力が正確に相殺され、2秒後の誤変位が1mm未満であること。
6. **タイムスタンプ途絶処理**: 100msを超える欠落時に安全にリセットされ、不正な長距離ジャンプが発生しないこと。

実行コマンド:
```sh
uv run python -m unittest tests/test_translation.py -v
```
