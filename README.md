# AIR Observatory

Nreal Airの回転と並進（6DoF）を推定し、ブラウザ上でメガネモデル・3D軌跡・センサー波形をリアルタイムに可視化するローカルビューアです。

---

## クイックスタート

### 1. 接続と起動

初代Nreal Air (`VID:PID = 3318:0424`) をMacに接続します。

- **GUIから起動**: **[Air Viewer.command](<Air Viewer.command>)** をダブルクリック
- **ターミナルから起動**:
  ```sh
  uv run air-viewer
  ```

※ ポートを変更する場合: `uv run air-viewer --port 8766`  
※ 初回起動時は本体からの校正データ読み出しに数秒かかります。

### 2. ブラウザで確認

ブラウザが自動で開きます（開かない場合は以下へアクセス）:
👉 **http://127.0.0.1:8765**

- **終了方法**: 起動したターミナルで `Ctrl + C` を押します。
- **動作環境**: macOS、Python環境（`uv`で管理）。外部CDNや追加のフロントエンド依存はありません。

## 主な機能

### 1. 6DoF姿勢・並進の可視化
- **回転（3DoF）**: 公式VQFアルゴリズムによる高精度な回転推定。
- **並進（3DoF）**: ワールド座標系での加速度二重積分による位置・速度推定および3D軌跡描画。
- **ゼロ速度補正（ZUPT）**: 静止判定時に速度をゼロにする補正機能（任意でON/OFF可能）。
- **正面 / 位置リセット**: 表示の正面方向リセット、位置・速度のゼロリセットを個別実行可能。

### 2. センサー波形と状態監視
- **リアルタイム波形**: 3軸ジャイロ、3軸加速度、地磁気の波形・現在値・デバイス温度を表示。
- **ステータス表示**: 静止判定フラグ、推定ジャイロバイアス、磁気状態（外乱検知・学習状況）。
- **時間レンジ切り替え**: 波形の表示幅（5秒 / 10秒 / 30秒）の変更、表示の一時停止に対応。
- **ヘルスチェック**: センサー応答途絶時の状態通知と自動再接続。

### 3. データ記録・エクスポート
- **CSV保存**: 直近60秒間の表示データ（両方式の姿勢角、位置、速度、線形加速度、バイアス、判定フラグ等）をワンクリックで書き出し。
- **フルサンプル記録**: 実機IMUの全パケット（約1,000Hz）を保存するキャプチャツール付属。

## 測定と姿勢推定の仕組み

### サンプリングと配信レート
- **実機IMU**: 約1,000Hzでサンプリング。受信した各サンプルで姿勢推定・慣性積分を更新します。
- **画面表示・CSV**: ブラウザへのServer-Sent Events (SSE) 配信およびCSV保存用メモリには、最大50Hzで最新値を間引いて渡します。
- 全生サンプル（1,000Hz）を記録する場合はキャプチャツールを使用します:
  ```sh
  uv run air-capture --seconds 15
  ```

### 回転推定（VQF）
- [VQF (Versatile Quaternion-based Filter)](docs/vqf.md) を採用。
- **地磁気なし（初期設定）**: 静止時・動作時のジャイロバイアスを推定。
- **地磁気あり（比較用）**: 地磁気による方位補正を追加。磁気外乱検出および参照学習状態も同時に表示。
- 必要に応じてブラウザ画面の「正面をリセット」を押して表示基準を調整します。

### 並進推定（慣性積分）
- 姿勢推定クォータニオンを用いて加速度をワールド座標（Y-up）へ変換し、重力加速度成分（9.80665 m/s²）を除去した上で台形則により速度・位置へ二重積分します。
- **制約事項**: 外部位置トラッキング（カメラやLiDAR等）を持たない純粋な慣性積分であるため、重力除去誤差やセンサーバイアスに起因する位置ドリフトが生じます。詳細は [並進の計算・操作・検証](docs/translation.md) を参照してください。

### 工場校正と座標軸
- 画面の生波形グラフは、センサー固有軸（工場校正未適用）で表示します。
- 姿勢推定には、本体内蔵の工場校正値（バイアス・スケール）および公開ドライバー（Monado等）に準拠したセンサー間軸合わせを適用しています。
- 地磁気の絶対単位や真値方位との厳密な精度比較は未検証のため、地磁気ありモードは比較検証用として位置づけています。

## フォルダ構成とファイル管理

```text
.
├── Air Viewer.command     # macOSダブルクリック起動用スクリプト
├── src/nreal_air/         # コア実装（HID通信、VQF姿勢推定、並進積分、HTTP/SSEサーバー）
├── web/                   # フロントエンド（HTML/CSS/JS、外部依存なし）
├── tests/                 # 自動テスト（ユニットテスト、固定パケットフィクスチャ）
├── tools/                 # 実機検証・フィルター比較用スクリプト
├── docs/                  # 技術仕様・設計ドキュメント
├── local/notes/           # 作業日誌・過去の調査資料（※Git対象外）
└── data/                  # 取得データ・個体校正・ログ・レポート（※Git対象外）
```

- 設計思想およびGit管理・ローカル管理の切り分け方針については [ファイルの管理方針](docs/repository.md) を参照してください。
- ハードウェア通信仕様の詳細は [HID通信と取得データ](docs/device-analysis.md) を参照してください。

## テストと検証

### ユニットテスト（実機不要）
固定フィクスチャを用いたアルゴリズムおよび通信デコードのテスト:
```sh
uv run python -m unittest discover -s tests -v
```

### 実機ライブ検証
Airを接続しビューアを起動した状態で、データ取得レート、SSE配信、CSV出力、姿勢・並進のデータフローを総合検証:
```sh
uv run python tools/verify_live.py
```
検証結果は `data/reports/live-verification.json` に出力されます。
